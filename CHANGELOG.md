# Changelog

All notable changes to Loadout are documented in this file. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Automated CodeQL analysis and dependency updates.
- Reproducible tagged releases with ZIP archives and SHA-256 checksums.
- A concise product overview and explicit release verification instructions.

## [0.1.0] - 2026-07-27

### Added

- Real-time hardware monitoring and system inventory.
- Surge mode with reversible power, memory, and process optimizations.
- Categorized cleanup with preview, risk labels, and confirmation.
- Reversible registry tweaks with original-value backups.
- WPF interface, structured logging, automated tests, and CI.
